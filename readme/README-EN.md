# Local AI Framework Platform

A local-first AI framework platform for Windows, macOS, and Linux, built with Java, Avalonia, llamafile, and AgentScope Java.

The control plane listens only on `127.0.0.1:17890` and provides chat, settings, plugin management, and an AI capability layer (Tool / MCP / Skill / RAG / Memory). Installation and core features work offline; import a local model before the first chat.
